Controls

  • Move: WASD or Arrow Keys
  • Aim: Mouse
  • Attack: Hold left mouse
  • Skill: Q for class skill
  • Mobility: Space
  • Pojo: Mouse throws fireballs, Q breathes fire, and pickups heal instead of paying out.
  • Sage: Q/E/R/F/Z/X/C/V elements, Left/Right/Middle cast, Alt/Shift+Left fissure, T rune, Backspace clear
